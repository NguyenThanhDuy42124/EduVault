# EduVault: Smart Contract-Audited Academic Equipment Lending Platform

## Overview
**EduVault** (*Hệ thống Quản lý và Kiểm toán Mượn trả Thiết bị Đào tạo dựa trên Smart Contract*) là nền tảng kết hợp:
- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons
- **Backend**: Python 3.13 + FastAPI + SQLAlchemy 2.0 + MySQL 8.x + Web3.py
- **Smart Contract**: Solidity ^0.8.24 + Hardhat Local EVM (Simulated Deposit Accounting)

Xem chi tiết kiến trúc, mô hình dữ liệu và đặc tả tại `findings.md`.
